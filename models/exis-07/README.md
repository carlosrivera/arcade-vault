# EXIS 07 — img2threejs reconstruction

A procedural Three.js reconstruction of the EXIS 07 strike craft, built with the
`img2threejs` skill from a four-view concept sheet. Open `index.html` on the local server.

## What this is
Reconstruction-by-code. The craft is a **polyhedron** — every surface is a flat facet
meeting its neighbours at a hard crease — so the hull is authored as explicit vertices:
nine cross-section stations lofted with per-face normals. That reproduces the subject
exactly rather than approximating a curved fuselage. Nothing in `exis07Build.ts` smooths a
normal.

## Reference handling
`check_reference_admission.py` **rejects the four-view sheet** as a reference — largest
connected blob 0.46 of foreground, i.e. fragmented — which is correct: a sheet of four
renders is not one admissible reference. The four view crops are admitted individually and
are the reference set; `crops/threequarter.png` is the primary review view.

## Source
- `src/createExis07Model.ts` — generated by the skill from the spec. Not hand-edited.
- `src/exis07Build.ts` — the `refine-code` artifact: the real geometry.
- `./build.sh` — transpiles both to `dist/` with Deno; three stays external and resolves
  through the site's import map to the vendored copy.

## Viewer flags
- `?bg=key` — black backdrop, HUD hidden, **bloom off**, and the solved review distance.
  Bloom is disabled here because the halo is bright and saturated: with it on, the
  segmenter counted the glow as subject and silhouette area read as high as 0.86 of frame.

## Where it stands
Turntable gate passes first time (0 interior holes at all four azimuths, reliable
segmentation). Part coverage passes with 0 errors across 55 named parts. The reference
camera was **solved** by sweeping azimuth/elevation/distance against the silhouette
metrics — az 38, el 30, 1.6× bounding radius — giving aspect delta 0.003 and scale delta
0.063, both inside threshold, so the residual **silhouette IoU 0.615** against a 0.85
threshold is real shape difference rather than framing.

**Two of five critical features pass:**
- `propulsion-cluster` **0.88** / 0.80 — three octagonal nozzles, five grille bars central
  and four per outboard, matching the rear view.
- `material-response` **0.84** / 0.80 — satin charcoal, clearcoated canopy tint, emissive
  that holds brightness on unlit faces, non-emissive orange vents.

**Three below threshold:**
- `dorsal-assembly` 0.76 / 0.78 — canopy reads, but smaller than the reference's.
- `faceted-hull` 0.72 / 0.80 — the design language is right; the faceting is coarser than
  the reference, which subdivides the nose and forward hull far more finely.
- `emissive-routing` 0.70 / 0.80 — the reference's large forward-hull V is not modelled,
  and the nose chevron sits low enough that it only reads from underneath.
- `trailing-structure` 0.70 / 0.72 (important, not critical) — plates read as flat shelves
  rather than stacked swept blades.
