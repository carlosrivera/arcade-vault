# Isle Diorama — img2threejs reconstruction

A procedural Three.js reconstruction of an isometric fantasy diorama island, built with the
`img2threejs` skill from a single reference painting. Open `index.html` on the local server.

## What this is
Reconstruction-by-code, not photogrammetry. The reference was classified into biome regions
and un-projected from its isometric view into a plan-view grid (`layout.json`), which drives
the terrain, the coastline and the placement of every landmark. No reference pixels are
mapped onto the mesh — see `projection-route.md` for why projection was rejected here.

## Pipeline artifacts
| File | What it is |
|---|---|
| `image-analysis.md` | The eight-layer observation pass |
| `reference-suitability.md` | Suitability verdict: **conditional → stylized**, with the reasoning |

| `assessment.json` | Object class, complexity scoring, quality contract |

| `renders/` | Review render, turntable, comparison sheet, gate results |

## Source
- `src/createIsleDioramaModel.ts` — generated by the skill from the spec (materials, lights,
  camera helpers). Regenerated from the spec; not hand-edited.
- `src/dioramaBuild.ts` — the `refine-code` artifact: the actual geometry, driven by
  `layout.json`.
- `./build.sh` — transpiles both to `dist/` with Deno. three stays external and resolves
  through the site's import map to the vendored copy.

## Viewer flags
- `?bg=key` — black backdrop, HUD hidden. Required for any capture a deterministic gate will
  segment; the studio navy is saturated enough that the segmenter classifies it as subject.
- `?nocloud=1` — hides the free-floating cloud masses for the turntable's hole check.

## Where it stands
Turntable gate passes (0 interior holes at all four azimuths); part coverage passes with no
errors; silhouette IoU 0.76 against a 0.85 threshold, with aspect and scale within tolerance.

Four of five critical features remain below threshold, each named in the recorded review
(`object-sculpt-spec.json` → `reviewHistory`):
- **landform-grammar 0.68/0.80** — the massif reads as concentric contour bands rather than
  a faceted pyramidal peak, and sits taller in frame than the reference's.
- **landmark-set 0.50/0.78** — all ten landmarks exist at their un-projected positions, but
  most are too small to read at the review viewpoint.
- **water-system 0.70/0.80** — shallows narrower and foam thinner than the painted surf.
- **painted-finish 0.74/0.82** — correct in kind (no toon ramp, no outline, no rim light),
  but darker and lower-contrast than the reference's high-key painting.

`slab-and-strata` passes at 0.86.
